# Modular sprites (single-sprite workflow)

Paperdoll Pose/Outfit/Head layer import is retired.

1. Open **Arthurian → Art & Stage Architect → Tab 1**
2. Category is fixed: **Sprite**
3. Crop / Save Splices → `Assets/Art/Spliced/Sprite`
4. Sprites register into `ModularSpriteLibrary` (`basePoses`) for pews after Verify / New Game

If pews show empty boxes: **Arthurian → Art Tools → Verify & Sync Modular Library**, then New Game.
